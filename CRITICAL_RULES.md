CRITICAL CULTURAL DAILY RULES — DO NOT VIOLATE

These rules override any general AI behavior, summarization behavior, rewriting behavior, SEO optimization behavior, or “best judgment” behavior.

1. H1 / ARTICLE TITLE
- Never shorten the H1.
- Never rewrite the H1.
- Never “improve” the H1.
- The H1 must remain exactly as provided by the client/source unless I explicitly instruct otherwise.

2. ARTICLE BODY TEXT
- Do not reword the article.
- Do not paraphrase the article.
- Do not summarize the article.
- Do not “clean up” tone or style unless explicitly instructed.
- Preserve the source text as faithfully as possible.
- Only make minimal required formatting edits, typo fixes if clearly authorized, or exact publication formatting adjustments.
- Accuracy of original wording is mandatory.

3. CLIENT-PROVIDED IMAGES
- If the client provides a photo, always use that photo first.
- Do not replace it with a different AI-selected image.
- Do not search for a “better” image if a client image already exists.
- If a client image is provided, the system must not source its own hero image.

4. IMAGE SOURCE / REVERSE SEARCH LOGIC
- If the client provides an image, attempt to identify the original source via reverse image search or metadata lookup.
- If the original source can be found, use that source for citation.
- If the original source cannot be found, use the client-provided image anyway.
- Do not discard the provided image just because the source cannot be found.
- In that case, continue with normal sizing, upload, and citation rules as applicable.

5. IMAGE HANDLING
- If a client image exists, use it as the hero image unless I explicitly say otherwise.
- Apply all normal rules for:
  - sizing
  - featured image setup
  - citation formatting
  - placement
  - social image generation
- Bad photo substitution is not allowed.

6. DONATION SECTION / DONATION LINK
- Never reword the donation section.
- Never rewrite donation language.
- Never shorten it.
- Never “improve” it.
- Preserve it exactly as required by house style.

7. CATEGORY / POST TYPE
- Do not assign sponsored category unless explicitly required by the rules.
- Follow the Cultural Daily rules exactly.
- “Check This Out” must always be selected for these posts.
- This is mandatory.

8. FOCUS KEYWORD
- Focus keyword must be short and precise.
- Do not make the focus keyword a long phrase.
- Do not use the full title unless explicitly instructed.
- Use the primary subject term only.
- Example: for a bone broth article, use the concise core term, not an overextended phrase.

9. SOCIAL IMAGE
- Always select a social image.
- Never skip the social image.
- Social image is mandatory.

10. SOCIAL IMAGE SIZE
- Social image must be exactly 1920 x 1400.
- Do not use approximate dimensions.
- Do not leave it uncropped or incorrectly sized.

11. AI LIBERTY POLICY
The system is not allowed to take creative liberties in any of the following:
- H1
- article wording
- donation text
- category logic
- image replacement when a client image exists
- focus keyword expansion

If uncertain, preserve the original and flag for manual review.

- Publish faithfully.

  - Yes:

    - Follow normal external image sourcing workflow.

- Social image must always be created/set.
- Social image must be exactly 1920x1400.

E. DONATION BLOCK
- Preserve exact required wording.
- Do not rewrite.

F. TAXONOMY
- Must always be “Check This Out” where applicable by house rule.
- Do not incorrectly assign “Sponsored” just because the post is sponsored content.

G. SEO
- Focus keyword must be short, exact, and not bloated.
- If uncertain, choose the most compact core keyword.

H. FAILURE MODE
- When uncertain, stop and flag for manual review.
- Do not improvise.
